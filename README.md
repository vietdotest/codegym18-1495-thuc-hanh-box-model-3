# Thực hành Box Model 3

Giữ nguyên kích thước, padding, border, shadow và border-radius của đoạn mẫu. CSS nằm trong style.css. Ở màn hình nhỏ chỉ bỏ margin mặc định của body để ví dụ vừa chiều rộng.

## Chạy
Mở index.html trong trình duyệt.
